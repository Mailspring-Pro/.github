## Inside Mailspring Pro

Mailspring Pro is a local Windows mail app with a named spring desk, a short folder list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside accounts you already keep and holds only the folder that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra folders wait for their own title. Mailspring Pro starts with a local profile and does not need a complex account system.
